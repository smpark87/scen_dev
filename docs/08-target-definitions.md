## 0. 왜 지금 정하고 동결하는가

회귀를 돌려본 뒤 대상을 고르면 **결과를 보고 표본을 고르는 것**이다.
"의미 변수가 잘 맞는 대상"을 사후에 뽑으면 그 R² 는 발견이 아니라 선택이다.

그래서 W2 말에 목록을 얼린다. 이후 추가는 가능하되 **추가했다는 사실과
그 시점을 기록**하고, 최초 목록과 나눠 보고한다 (charter §7 "채택은 느리게").

---

## 1. 기준 가격

| 기호 | 계열 | 기간 | 쓰는 이유 |
|---|---|---|---|
| **hhf** | Henry Hub **선물 근월** (`hub_prices`) | 2010-01~ | **주 기준.** 시장의 전망이 담긴 가격. 현물보다 날씨 소음이 적다 |
| hh | Henry Hub **현물** (`gas_daily_prices`) | 2020-01~ | 물리 수급의 즉시 반영. 꼬리·변동성에서 대조로 함께 본다 |

두 계열 모두에 대해 같은 대상을 계산해 **결론이 가격 정의에 의존하는지** 확인한다.

## 2. 대상 7종

분석창 = 2023-01-01 ~ 2026-07-31, 평일 935일. 아래 수치는 그 구간 실측이다.

### T1 방향 지속성 — **주 대상**

```
r_past = log(P_t / P_{t−5})          최근 5일 방향
r_fwd  = log(P_{t+5} / P_t)          이후 5일
T1     = sign(r_past) × r_fwd        양수면 방향이 이어졌다
```

| | |
|---|---|
| 형태 | 연속 (이진 보조: 같은 방향 여부) |
| 실측 | n=923 · 평균 −0.0125 · sd 0.1105 · **같은 방향 49.0%** |
| 유효 표본 | `T1_valid` — \|r_past\| 가 중앙값 이상인 554일. 움직임이 0 에 가까우면 sign 이 잡음이다 |

> **왜 주 대상인가.** "언제 바뀌는가"보다 **"지금 방향이 이어지는가"** 가 실무에서 훨씬
> 자주 필요한 판단이다. 정형 변수는 관성을 보여주지만 **왜 계속되는지는 담지 못한다.**
> 텍스트에 그 근거가 있고, 근거가 사라지면 관성도 깨진다 (06 §4.0.2).

**무조건부로는 49% — 동전이다.** 이것이 오히려 좋다. 어떤 향상이든 의미가 있다.

### T2 익일 수익률 — 대조군

```
T2 = log(P_{t+1} / P_t)
```
n=931 · sd 0.0733 · 자기상관 −0.24(하루 되돌림).
**정형이 지배할 것으로 예상하는 자리.** 여기서 의미 변수가 약한 것은 실패가 아니라
가설과 일치하는 결과다 (06 §4.0.2 (나)).

### T3 강도 변화

```
T3 = log( (|r_fwd| + f) / (|r_past| + f) ),  f = 60일 변동성 × 0.1,  [−4, 4] 절단
```
n=923 · 평균 −0.0827 · sd 1.2573. 같은 방향이어도 **약해지는가**를 본다.
분모 0 근처에서 꼬리가 폭발해 바닥값 `f` 를 둔다.

### T4 변동성 변화

```
T4 = log( 향후 10일 실현변동성 / 직전 20일 실현변동성 )
```
n=927 · 평균 −0.2563 · sd 1.0958 · **자기상관 0.87**(창 중첩).
"불확실성은 텍스트에 먼저 온다"는 가설의 시험대.

### T5 체제 이탈 — 전환의 대용

```
z = log(P_{t+10}/P_t) / (σ_60 × √10)
T5 = 1 if |z| > 1.25          (연속형 |z| 도 함께 보관)
```
n=922 · **발생률 6.5%** · \|z\| 평균 0.459.

> 초안은 2σ 였는데 **발생률 0.8%(7건)** 으로 모형화가 불가능했다. 1.25σ 로 완화하고,
> 임계값 선택에 결론이 좌우되지 않도록 **연속형 \|z\| 를 주력으로** 둔다.

### T6 저장량 nowcast — 발표 전 구간

```
T6 = 다음 EIA 주간 저장 순변화 (Bcf)
관측 시점: 발표 **직전 3영업일만**
```
n=558 · sd 98.3 Bcf.

> **의미 변수가 가장 유리할 것으로 보는 자리.** 공식 통계가 아직 없는 구간이라
> 정형 정보원이 없는데(06 §4.0.2), 코퍼스 본문에는 컨센서스가 문자로 들어 있다 —
> 실제 확인된 문장: *"Analysts Expect 106 Billion-Cubic-Foot Rise in U.S. Natural Gas
> Inventories"*, *"Nearly In-Line Storage Build Leaves Futures Treading Water"*.
> 발견한 축 `ax_2_1`(날씨 주도 ↔ 재고 발표 반응)이 여기에 직접 대응한다.

⚠️ 발표 직전 3일로 제한한 이유: 매일 같은 주간값을 반복하면 자기상관 0.97 로
유효 표본이 주 단위인데 일 단위인 척하게 된다. 제한 후에도 0.95 라 **추론은
주 단위(약 185주)로 한다.**

### T7 꼬리 — 극단 변동일

```
T7 = 1 if |log(P_{t+1}/P_t)| > 분석창 95분위
```
근월 4.1% · 현물 4.8%. "사건은 텍스트에 먼저 나타난다"의 직접 시험.

## 3. 국면 분할 (06 §4.0.2 (다))

t 시점에 **알 수 있는 것만**으로 나눈다. 분위는 분석창 안에서 끊는다
(전체 기간으로 끊으면 2023~ 이 고변동에 몰려 3분할이 157/298/480 으로 깨졌다).

| 축 | 구분 | 일수 |
|---|---|---|
| `regime_vol` | 저변동 / 중변동 / 고변동 (20일 실현변동성 3분위) | 315 / 307 / 313 |
| `regime_trend` | 하락추세 / 횡보 / 상승추세 (20일 추세 z 3분위) | 307 / 315 / 307 |

**이미 나온 결과 하나** — T1 을 국면별로 쪼개면:

```
저변동 46%   중변동 43%   고변동 59%      (동전 = 50%, n=150/206/194)
```

**고변동 국면에서만 추세가 이어진다.** 이것은 아직 아무 설명변수도 넣지 않은
순수 관측이며, "국면마다 기여도가 다르다"는 06 §4.0.2 (다)의 전제를 지지한다.

## 4. 통계적 주의 — 미리 못박는다

| 항목 | 내용 |
|---|---|
| **창 중첩** | T1·T3·T4·T5 는 t→t+5, t+10 을 쓴다. 인접일 관측이 겹쳐 유효 표본은 일수보다 훨씬 적다. **블록 부트스트랩**으로 추론한다 |
| **T6 주 단위** | 자기상관 0.95. 일 단위 유의성은 무효. 약 185주로 센다 |
| **다중 비교** | 대상 7 × 시차 4 × 국면 6 = 최대 168회. 전부 보고하고, **대상별 최고치만 뽑아 보고하지 않는다** |
| **as-of 미적용** | 데모 전제. 저장·리그는 발표 후 유지(ffill)라 실제로는 관측 불가 시점에 값이 있다. 예측력 주장 금지 |
| **유가 결측** | `oil_prices` 2026-01-28 ~ 06-01 수집 공백(124일). 메우지 않았다 |

| 5 | 지역 대상 추가 여부 | 데모에서는 **HH 만** | Waha 베이시스 추가 — 지역 질문(03 §5.1.2)의 예고편 |

변수도 바뀐다"* 를 데모에서 직접 보일 수 있지만, 대상이 늘어 다중 비교 부담이 커집니다.
