# 본사 소스코드 자가점검 기록

이 문서는 본사 배포 도구의 실제 실행과 판정을 기록한다. 개발용 `scripts/security_source_gate.py` 및 품질 래칫은 본사 규칙 전체를 구현하지 않으며 공식 승인이나 배포 판단을 대신하지 않는다.

## 개발 중 회귀 게이트

- 자가점검 전 `python scripts/security_scan_preflight.py`로 검사 범위를 확인한다. 잔여 `debug/`나 내부 Git 작업 트리는 소유자를 확인해 정리하고, 제외 설정으로 숨기지 않는다.
- 커밋 전 `python scripts/security_source_gate.py --staged`를 실행한다. CI는 전체 작성 소스와 변경된 위험 API를 검사한다.
- 맥락상 안전한 위험 API는 `scripts/security_reviewed.json`에 코드와 한국어 근거를 남긴다. 본사 도구의 오탐 판정·예외 승인은 별도다.

## 본사 도구 실행 기록

| 실행일 | 도구 버전·검사 범위 | 원본 보고서 위치 | 발견·조치·미해결 판정 |
|---|---|---|---|
| 미실행 | 이 문서 작성 시점에 검증된 실행 기록이 없다 | — | 실행 후 기록한다 |

보고서 원본에 자격증명·개인 정보·운영 데이터가 포함될 수 있으므로 Git에 넣기 전에 내용을 확인한다. 범위와 판정이 확정되지 않았으면 건수 0이나 PASS로 기록하지 않는다.
