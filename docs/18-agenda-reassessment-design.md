# 카테고리별 아젠다의 정기·수동 재평가

작성: 2026-09-23. 상태: 최근 사용자 합의 기록 + 실행 방식 제안.
스케줄·자동화·LLM 호출·운영 job을 생성하거나 배포하지 않았다.

**후속 사용자 지시:** 아젠다 선정·재평가는 통계 분석 모형으로 축을 추출하는 단계로 만들지
않는다. LIORA가 전문가처럼 문서를 조사하고 상반된 근거를 검토해 주목할 주제와 관점을
제안하는 리서치·해석 과정으로 설계한다. 정형 수치는 이 판단을 뒷받침하는 사실 자료로
사용할 수 있으나, 회귀·요인 추출·상관 점수를 아젠다 선정의 필수 절차로 두지 않는다.

## 1. 현재 합의와 이전 설계의 보완

미국 에너지 전반이 전망의 중심이며 관찰 범위는 글로벌이다. 카테고리는 상시 관찰 범위,
아젠다는 그 안에서 추적할 구체적 변화·질문이다. 다차원 세계를 표현·조정할 AXIS와
아젠다의 구체적인 대응 관계는 다음 설계 과제다. 세 개념을 같은 목록으로 취급하지 않는다.

사용자가 설명한 AXIS의 목적은 정치·기술·경제 등 여러 방향의 조합으로 가능한 세계를
탐색·시뮬레이션하는 것이다. 16~17번 문서의 주요 주제 발견 절차는 이 목적을 위한 일부
단계이며, 그것만으로 AXIS 설계가 완료되는 것은 아니다. '공급망의 자국 중심 재편'처럼
여러 요인을 이미 종합한 세계를 개별 관찰 요인과 같은 단계에 놓지 않는다.

현재 카테고리는 다음 일곱 개다. 세부 범위는 후속 검토로 수정 가능하며 고정된 아젠다 수를 두지 않는다.

| 카테고리 | 관찰 범위 |
|---|---|
| Politics & Governance | 국가와 시장의 역할, 정부 개입, 정치적 가치와 우선순위 / 권한 배분, 견제와 균형, 의사결정·집행 역량, 제도의 안정성 |
| Geopolitics & Trade | 외교·안보·전쟁·동맹·제재·관세·교역 접근과 국가 간 관계 |
| Economy & Finance | 경기·산업 활동·물가·금리·환율·신용·투자와 자본 배분 여건 |
| Society & Demographics | 인구·가구 구성·거주 분포 / 생활·이동·소비 방식 / 에너지 기술·시설의 사회적 수용성 |
| Technology | 기술의 성능·비용·재현성·실증·상용화·확산 조건 |
| Environment & Climate | 탈탄소 요구·환경 제약·기후·기상·자연재해·자연조건 |
| Resources, Infrastructure & Industry | 자원 기반·생산 및 수송 능력·설비/망·건설 역량·공급망과 사업자 구조 |

Politics & Governance는 정치 이념과 통치 구조를 본다. 개별 탄소 규제·통상 조치·경제 정책의
내용은 해당 분야에서도 보고 정치적 배경을 연결한다. Society & Demographics의 공중보건은
독립 필수 하위 주제가 아니라 생활·이동·근무 등과 연결될 때 다룬다.

하나의 아젠다에는 여러 카테고리가 붙을 수 있다. 각 카테고리마다 별도 복제본을 만들지 않는다.
중요도가 낮은 카테고리도 관찰을 유지하되, 자료가 없으면 중요하지 않음으로 해석하지 않는다.
매번 모든 카테고리에 새 아젠다를 만들 필요는 없다.

## 2. 하나의 재평가 절차, 서로 다른 실행 계기

정기 실행과 사용자의 Reassess는 같은 평가 절차를 호출한다. 다음 빈도는 **제안**이며 확정된 일정이 아니다.

| 실행 계기 | 범위 | 의도 |
|---|---|---|
| 매일 정기 점검 | 직전 성공 실행 이후 새로 들어오거나 수정된 자료 | 기존 관찰 조건의 변화와 새 징후 확인 |
| 매주 전체 재평가 | 모든 카테고리, 기존 아젠다와 보류 후보, 반대 근거·관찰 공백 | 현재 관점 전체의 유지·수정·추가·통합 검토 |
| 수동 Reassess | 전체 / 특정 카테고리 / 특정 아젠다 | 동일한 절차를 즉시 실행하고 요청 사유에 맞는 질문을 추가 검토 |

전체 재평가도 매번 원문 전체를 내려받거나 다시 요약하지 않는다. 검증된 근거 기록을
재사용하되, 오래된 핵심 근거는 정기적으로 원문·효력·철회 여부를 다시 확인한다.
느린 인구·설비 통계는 발표 주기에 맞춰 반영한다. 신자료가 없으면 상태를 유지할 수 있다.
주말·기준 시간대·실행 시각·전망 기간별 구분은 실제 스케줄 구성 전에 정한다.

## 3. 재평가 안에서 할 일

### A. 평가 시점과 자료 범위 고정

실행 ID, 요청 시각, 관측 기준일, 전망 기간, 대상 시장, 직전 관점 버전, 요청 범위·사유를
먼저 기록한다. 정형 자료의 발표·수집·수정과 문서의 발표·사건·수집 시각을 구분한다.
발표일만 기준으로 증분 조회하면 뒤늦게 수집된 옛 문서와 정정 자료를 놓칠 수 있으므로,
수집/수정 이력을 기준으로 자료를 찾고 적용 가능한 시점을 별도로 판단한다.

### B. 관측과 근거 추출

- 정형 자료: 새 관측·수정값과 기존 관찰 조건의 충족 여부를 사실 자료로 확인한다.
  아젠다를 통계 모형의 출력으로 선정하지 않는다.
- 비정형 자료: 누가, 무엇을, 언제, 어디에서, 어느 규모로 바꾸었는지 근거 위치와 함께 추출한다.
- 선언·제안·확정 결정·집행·실적·외부 전망을 구분한다. 출처의 전망을 관측 사실로 저장하지 않는다.
- 같은 발표의 재인용은 한 사건으로 묶는다. 재보도 기사 수를 독립 증거 수로 세지 않는다.
- 원문 사실과 LIORA의 해석·가설을 구분하며, 지지·반대·미확인 근거를 모두 연결한다.

### C. 기존 아젠다 추적과 새로운 후보 탐색

기존 아젠다별로 새로운 근거가 방향·적용 범위·중요도 판단을 바꾸는지 본다.
동시에 기존 아젠다와 무관한 카테고리별 탐색과 새 발표 자료 확인을 유지한다. 기존 목록과
유사한 문서만 찾는 방식으로 닫지 않는다. 새로운 기술의 작은 실증·반복성처럼 기사량이
적은 신호도 기록할 수 있어야 한다. 발견되지 않은 것은 '없음'과 '관찰 부족'을 구분한다.

### D. 해석과 대안 검토

AI는 근거 묶음과 기존 판단을 받아 갱신안을 제안한다. 그 뒤 별도 검토 단계에서 핵심
주장이 실제 근거에 의해 뒷받침되는지, 반대 해석을 빠뜨렸는지, 미국 에너지 연결이 있는지
검토한다. 두 단계가 같은 계열 모델을 사용하면 독립적인 검증이 된다고 주장하지 않는다.

결과는 신규 후보, 기존 유지, 방향/내용 수정, 중요도 재평가, 다른 아젠다와의 통합/분리,
약화·종료의 제안으로 남길 수 있다. 새로운 증거가 없는데 표현만 달라진 것은 시장 변화로
계산하지 않는다. 기존 근거의 오류나 다른 해석을 발견했다면 '해석/오류 수정'으로 기록한다.

현재 영향, 앞으로 확산될 가능성의 근거, 판단의 확실성은 분리한다. 단일 AI 점수를
발생확률로 표시하지 않고, 잠재적 영향이 크지만 자료가 부족한 후보도 관찰 대상으로 남긴다.
관찰 후보의 수명이 짧다는 이유만으로 자동 삭제하지 않으며, 약화·종료에도 사유를 남긴다.

### E. 카테고리 사이의 일관성 검사

한 아젠다는 공통 ID를 갖고 관련 카테고리에 연결한다. 이름 변경은 새 아젠다 생성과 구분하며
병합·분리에는 계보를 남긴다. 평가 범위를 특정 카테고리로 좁혀도 관련된 공통 아젠다와
인접 관계는 함께 확인한다. 별개의 축으로 정량화할 때 같은 충격을 중복 계산하지 않는다.

### F. 변경분과 새 버전 저장

현재 기준 관점에 변경안을 자동 반영할 때에도 출처·자료 시점·근거 연결·출력 형식·모순 검사를
통과한 실행만 새 버전으로 저장한다. 모든 변경에 매번 사용자 승인을 요구하는 운영은 목표가 아니다.
실패한 부분은 직전 유효 판단을 보존하고 마지막 성공 시점과 미갱신 이유를 표시한다.
미완료 결과를 전체 최신 관점으로 표시하지 않는다. 모델 호출·재시도·검토 횟수는 유한하게 제한한다.

동일 자료와 설정의 중복 요청은 새로운 시장 변화로 저장하지 않는다. 정기와 수동 실행이
겹치면 같은 범위는 합치거나 순서를 정하고, 오래된 기준 버전으로 만든 결과가 최신 판단을
덮어쓰지 않게 한다. 이를 위한 작업 큐·동시성 방식은 구현 단계에서 선택한다.

## 4. 아젠다별로 사용자가 읽을 결과

1. 현재 다루는 질문과 관련 카테고리.
2. 과거의 주요 변화 — 당시 판단을 보존하고 나중의 해석은 덧붙인다.
3. 현재 방향과 상태 — 사실·해석·불확실성을 구분한다.
4. 앞으로 가능한 방향과 그 방향을 지지/약화할 조건 — 여러 결과를 종합한 World와 구분한다.
5. 미국 Power / Gas / LNG / Oil에 연결될 수 있는 경로와 제약.
6. 다음에 관찰할 지표·문서·결정·사건.
7. 직전 평가와 달라진 내용, 수정 이유, 근거, 마지막 확인·실질 변경 시각.

카테고리별로는 주요 아젠다, 아직 작지만 관찰할 후보, 관찰 공백을 함께 읽는다.
'주요 변화 없음', '기존 흐름 지속', '자료 부족', '이번 재평가 실패'를 서로 구분한다.
카테고리마다 반드시 같은 수의 항목을 출력하게 하지 않는다.

## 5. 수동 Reassess의 의미

기본 동작은 최신 확보 자료와 기존 근거를 사용한 즉시 재평가다. 사용자가 추가한 질문이나
문서는 별도 입력으로 기록한다. '이 해석이 과한 것 같다'는 요청에는 반대 근거와 대안 해석을
찾지만 요청 문장 자체를 시장 사실로 취급하지 않는다.

'이 조건이라고 가정하면'은 What If 실험 요청이다. 그 가정을 관측 사실로 바꾸거나 기준
Perspective에 조용히 반영하지 않는다. 직접 작성한 연구 메모도 자동 갱신으로 덮어쓰지 않는다.
보충 외부 검색은 출처 범위와 비용을 정한 뒤 붙일 수 있으며 매 reassess마다 무제한 검색하지 않는다.

## 6. Projection과 연결할 때

Projection 실행은 특정 Perspective/AXIS 버전을 참조한다. 이후 정기 재평가가 기존 실행의
입력을 바꾸지 않는다. 새 관점이 생기면 관련 전망의 재계산 필요를 표시하고 새 실행으로 연결한다.
Projection의 민감도·모순·누락 발견은 재검토 사유가 될 수 있지만 새 외부 관측은 아니다.
모델 결과를 다시 시장 증거로 취급해 확신을 강화하는 순환을 만들지 않는다.

## 7. 현재 저장소에서 재사용할 것과 빈 부분

코드·기존 문서를 읽은 뒤 후속 사용자 질문에 따라 2026-09-23 중앙 DB의 문서 메타데이터와
본문 존재 여부를 읽기 전용으로 집계했다. 개별 원문을 정독해 일곱 카테고리의 충분성을
평가한 전수 검사는 아니다.

- `extract/chunks.py`: `db.py`를 통해 `ai_documents` / `ai_document_chunks`의 문서 ID,
  청크 ID, 출처, 제목, 발표일, 임베딩을 읽는 기존 배치가 있다.
- `extract/`의 정형 어댑터와 `outlook/evidence.py`: 중앙 DB 읽기 전용 접근을 재사용할 수 있다.
- 기존 배치는 아젠다 엔진이 아니다. 본문/인용 위치 조회, 문서 버전·정정·수집일 처리,
  자료의 카테고리별 편향 점검, 사건 중복 제거, 아젠다 이력·재평가 로직은 추가 설계·구현이 필요하다.
- 과거 데모 문서에는 자료 유형별 수록 기간 차이와 발표일 이상치가 기록되어 있다.
  따라서 기존 코퍼스가 일곱 카테고리를 충분히 대표한다고 가정하지 않는다.

실제 집계에서 확인한 내용:

- `article` 8,587건, `public_report` 분류 3,847건, `ferc_docket` 2,950건,
  `s3_markdown` 1,178건, `steo_outlook` 199건 등이 있다. 각 문서에는 비어 있지 않은
  본문 청크가 적어도 하나 연결되어 있다. 원문 전체의 완전성·추출 품질까지 보장하는 검사는 아니다.
- 주요 출처명에는 NGI, Criterion, Hart Energy, Reuters, Platts, World Oil, LNG Prime,
  FERC 등이 있다. `public_report` 가운데 3,575건은 출처명이 `news`여서 분류명만으로
  독립된 전문 연구보고서라고 간주하지 않는다.
- `conversation_memory` 125건, `background_context` 346건 등 사용자/내부 맥락도 있다.
  이는 관심사·이전 판단을 이해하는 자료로 분리하고 외부 사실의 독립 증거로 세지 않는다.
  시장 분석·논평 유형도 작성 주체와 생성 경위를 확인한 뒤 근거 역할을 부여해야 한다.
- 문서에 URL·S3 위치·출처 ID·페이지·청크·수집/갱신 관련 필드가 있다. `url`이 비어 있는
  유형도 있어 다른 필드를 통해 원문으로 돌아가는 경로를 확인해야 한다. URL 부재만으로
  원문 자체가 없다고 판단하지 않는다.
- 발표일 없는 문서와 미래로 기록된 문서가 일부 있다. 과거 재평가·신규성 판단 전에
  날짜의 의미와 품질을 확인한다. 문서의 `updated_at`은 과거 버전 보존을 보장하지 않는다.

현재 자료로 첫 재평가는 시작할 수 있다. 그러나 에너지 매체가 아직 주목하지 않는 기술 진보,
정치 이념·통치 변화, 사회·인구·행동 변화의 선행 자료와 서로 다른 견해의 장기 분석은
카테고리별 표본을 검토해 충분성을 확인해야 한다. 부족하면 기존 DB 검색 뒤 원자료 조사로
보충하는 경로를 연결한다. 지금 외부 검색을 했다고 LIORA 제품에 자동 검색이 구현된 것은 아니다.

전문가형 재평가에 추가로 필요한 것은 카테고리별 탐색 질문·출처 지도, 근거와 해석의 구분,
지지/반대 견해의 비교, 이전 아젠다와 관점의 이력, 일관된 검토 지침이다. 현재 대화로 목적과
범위는 상당 부분 정해졌지만 전망 기간과 결과의 상세 수준은 실행 예제를 보며 정해야 한다.
모든 자료를 먼저 완비하는 것을 첫 수동 재평가의 선행조건으로 삼지 않는다.

원천 데이터 수집·중앙 적재는 기존 NGIP 책임을 유지한다. OUTLOOK의 재평가는 그 자료를
읽는 분석 기능이다. 현재 scen_dev 개발은 읽기 전용이며 운영 계정 권한을 변경하지 않는다.
개발용 분석 결과는 제외 경로에 보존할 수 있으나 별도 원천 수집 DB를 만들지 않는다.
독립 LIORA 통합 시 분석 결과의 운영 저장과 스케줄 실행 위치는 별도 검토한다.

### 7.1. 거시경제·지정학·기관 전망 자료 보강

사용자 추가 요구: GDP·CPI 같은 정형 지표, 에너지에 한정되지 않은 지정학 기사,
WEO·IEA 자료도 전문가형 재평가의 입력으로 다룬다. 아젠다를 통계모델로 선정하지 않는다는
결정은 통계자료를 사용하지 않는다는 의미가 아니다.

2026-09-23 읽기 전용 추가 확인:

| 자료 | 확인된 보유 상태 | 보강할 내용 |
| --- | --- | --- |
| World Bank GDP | `market_indicators`의 `wb_gdp_` 계열 24,645행, 값이 있는 행 23,470개. 국가·지역 합계 등 265개 경제 단위, 1995~2025년 연간 기간. `extract/worldbank_gdp.py` 조회 어댑터 존재 | 미국의 최근 흐름을 읽을 분기 GDP 등. 연간 자료의 마지막 기간을 모든 국가의 최신 관측 보유로 해석하지 않는다 |
| CPI·물가 | 정형 지표 테이블의 metric 검색 및 조회 코드에서 CPI·inflation·PCE 계열을 확인하지 못함 | 미국 CPI를 우선 후보로 하고, 근원 물가·PCE 등은 해석 목적에 맞춰 범위 결정 |
| IEA / WEO | IEA 출처 뉴스 1건 확인. 문서 제목·위치·메타데이터의 WEO 검색 및 World Energy Outlook 본문 구문 검색에서는 보고서 적재를 확인하지 못함 | IEA WEO 원문·공개 데이터, 선택한 분야별 보고서의 판본별 확보 |
| IMF WEO | 문서 카탈로그 검색에서 World Economic Outlook 적재를 확인하지 못함 | 국가별 거시 전망과 보고서의 가정·위험 해석 |
| 지정학 기사 | Reuters·Bloomberg 등 출처는 존재하나 일반 정치·외교·전쟁·무역의 충분한 범위를 보유하는지는 미검증 | 에너지 키워드가 없는 선행 사건도 탐색할 범위와 출처 구성 |

WEO는 IEA의 **World Energy Outlook**과 IMF의 **World Economic Outlook**을 구분한다.
보고서가 인용된 기사, 기관 뉴스, 보고서 원문, 수치 데이터셋은 각각 다른 보유 상태다.
검색에서 찾지 못한 것을 모든 저장 위치에서의 부재로 단정하지 않되, 확인 전에는 보유로 계산하지 않는다.

입력 자료는 다음 역할을 함께 갖춰야 한다.

1. **관측 통계:** GDP·물가·고용·산업활동 등 변화의 규모와 흐름을 확인한다.
2. **사건·정책 원문과 보도:** 선거·정책·외교·제재·관세·분쟁 등의 발생, 결정 단계,
   집행 여부를 구분한다. 기사 수를 독립 증거 수로 취급하지 않는다.
3. **기관 분석·전망:** IEA·IMF 등의 해석, 전제, 대안 시나리오와 반대 견해를 읽는다.
   기관 전망을 관측 사실이나 발생 확률로 바꾸지 않는다.
4. **초기 변화 자료:** 연구·기술 실증·기업 투자·사회 변화 등 에너지 매체에 드러나기 전의
   징후를 찾는다. 에너지 연결이 아직 가설인 후보도 근거와 불확실성을 표시해 관찰한다.

수집 시점부터 에너지 키워드만으로 모든 자료를 제한하면 초기 징후를 놓칠 수 있다.
카테고리별 탐색은 넓게 하되, 채택할 때 미국 에너지로 이어지는 가능한 경로와 관찰 조건을
설명한다. 모든 세계 뉴스를 무제한 수집하는 설계는 아니다.
지표의 기준 기간·발표일·수정판과 전망 보고서의 발표 판본·시나리오 전제를 보존한다.
과거 시점 재평가에는 당시 공개되어 있던 값과 판본만 사용한다.

공식 연결 후보:

- BEA GDP: https://www.bea.gov/data/gdp/gross-domestic-product
- BLS 공개 시계열 API: https://www.bls.gov/developers/api_signature_v2.htm
- IMF WEO: https://data.imf.org/Datasets/WEO
- IEA WEO 예시 판본: https://www.iea.org/reports/world-energy-outlook-2025
- IEA 보고서 목록: https://www.iea.org/reports

다음 설계 산출물은 카테고리별로 '답할 질문 → 필요한 근거 → 출처 → 현재 보유/공백 →
갱신 방식'을 연결한 출처 지도다. 공식 페이지의 존재만으로 자동 수집 가능성이나 이용 조건,
원문 추출 완전성이 검증되었다고 간주하지 않는다. 이번 확인은 신규 job 구현·배포가 아니다.

### 7.2. WEO 정기 적재 job 방향

사용 목적은 사용자가 명시한 회사 내부 분석이며, LIORA나 해당 자료를 상업화할 계획은 없다.
이 전제로 범위를 설계한다. 다만 내부 업무 사용과 개별 라이선스의 비상업적 사용 요건을
자동으로 동일시하지 않으며, 보고서 본문과 별도 수치 데이터에 표시된 조건을 각각 적용한다.

사용자 논의에 따라 WEO는 필요할 때 검색만 하는 자료가 아니라 NGIP의 정기 적재 대상으로
설계한다. 앞선 외부 검색 방식은 일반 기사·새 쟁점의 탐색에 적용하고, 알려진 정기 발간물은
발행 여부를 확인해 축적한다. IEA와 IMF의 WEO는 별도 자료 ID와 수집기로 구분하며,
실제 첫 구현 대상은 기관·보고서 원문·수치 데이터의 범위를 명시한다.

제안 실행 흐름:

1. 공식 발간 목록에서 신규 판본·정정 여부를 주기적으로 확인한다. 주 1회 확인은 초기 제안이며
   실제 실행 주기로 확정하거나 배포한 것은 아니다.
2. 발행일·판본·원문 URL·수집 시각·파일 해시와 함께 허용된 원문을 보존한다.
   동일 내용은 중복 적재하지 않고 정정판은 이전 판본을 남긴다.
3. 보고서 본문은 페이지·절 등 근거 위치를 유지하며 기존 문서 검색 체계에 연결한다.
   공개 수치 파일은 별도로 검증하여 관측·추정·전망, 단위, 지역, 대상 연도, 시나리오를 구분한다.
4. 필수 필드와 추출 품질 검증을 통과한 판본만 사용 가능 상태로 바꾼다. 실패한 판본이
   직전 유효 자료를 대체하지 않게 하고 원인과 재시도 상태를 기록한다.
5. 새 유효 판본은 Perspectives 재평가의 입력 변경으로 전달한다. 수집 job 자체가
   아젠다나 전망을 확정하지 않는다.

IEA WEO 2025의 보고서와 Free Dataset은 별도 배포물이다. Free Dataset의 공식 페이지는
CC BY-NC-SA 4.0과 비상업적 사용 조건을 명시하므로, 무료라는 이유만으로 제품 사용 가능
범위를 확정하지 않는다. 해당 데이터의 실제 이용 범위는 연결 전에 확인한다.
출처: https://www.iea.org/data-and-statistics/data-product/world-energy-outlook-2025-free-dataset

IMF WEO는 공식 데이터 포털이 연 2회(4월·10월) 데이터베이스 발간 및 API·다운로드 경로를
안내한다. 실제 API 접근·파싱은 아직 검증하지 않았다.
출처: https://data.imf.org/Datasets/WEO

NGIP가 수집·중앙 적재를 소유하고 OUTLOOK은 읽기 전용으로 참조한다.
2026-09-23 사용자 구현 요청 후 NGIP `jobs/ingest_iea_weo.py`와 `jobs/_iea_weo.py`에
IEA WEO PDF 수집·판본 보존·기존 S3 코퍼스 연결을 구현했다. 기본 실행은 dry-run이며,
운영 계약과 검증은 NGIP `docs/IEA_WEO_JOB.md`를 기준으로 한다.
공식 2025 PDF 전체 변환은 성공했으나 HTML 발간 페이지는 실제 403이어서 자동 신규 판본
발견은 미검증이다. 명시적 판본 링크 수집을 자동 발견 성공으로 취급하지 않는다.
IMF WEO·별도 수치 데이터셋·Perspectives 재평가 트리거는 이번 구현 범위에 포함하지 않았다.
배포 정의의 스케줄은 기본 비활성이며 운영 적재·실제 스케줄 생성·배포는 수행하지 않았다.

## 8. 첫 구현 단위 제안

자동 스케줄을 연결하기 전에 **한 번의 수동 재평가**를 끝까지 실행한다.
작은 자료 묶음, 이전 아젠다 기록, 새 자료 묶음을 넣고 유지·수정·신규·자료 부족을 구별하며,
동일 자료로 재실행했을 때 불필요한 변화를 만들어내지 않는지 본다.

최소 검증 사례는 새 근거 없음, 하나의 발표를 재인용한 여러 문서, 기존 해석에 반하는 근거,
조용한 카테고리에서의 새 징후, 자료 수집 실패, 수정된 과거 데이터, 여러 카테고리에 걸친
동일 아젠다다. 그 다음 전체 일곱 카테고리 재평가와 정기 트리거를 연결한다.
첫 구현에서 사용자가 승인해야 하는 것은 실제 배포의 대상·범위이며,
현재 논의만으로 스케줄이나 job 배포를 승인받은 것으로 간주하지 않는다.
