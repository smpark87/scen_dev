# OUTLOOK — 엑셀 기준 데이터 확보 범위와 DB 공백

## 기준과 확인 범위

사용자는 기존 LNG·WTI 엑셀 모델에 있던 데이터를 최소한 확보하기를 원한다.
기존 미국 중심 DB를 읽어 재사용하되 유럽·아시아·기타 생산국까지 보완한다.
최종 선택된 회귀변수만이 아니라 원천 시트의 수요·공급·교역·기상·운임·거시 항목도
확보 대상으로 다룬다. 전체 데이터를 확보하는 것과 모든 변수를 회귀에 넣는 것은 구분한다.

2026-09-21 `db.py`를 통한 `scen_ro` 읽기 전용 연결로 테이블·칼럼과 계열별
지역·단위·출처·건수·기간을 확인했다. 운영 DB 쓰기는 수행하지 않았다.
아래의 미확인은 조회 가능한 정형 테이블에서 분석용 계열을 찾지 못했다는 뜻이다.
원문 문서나 미적재 벤더 파일에 해당 정보가 없다는 뜻은 아니다.
개별 관측값 품질, 전체 결측·중복, 원천 정의의 동일성은 아직 검증하지 않았다.

## 1. 엑셀 항목과 DB 대조

**2026-09-21 후속 진행:** GDP 3종의 NGIP job 배포와 중앙 DB 최초 적재·읽기 전용 조회를 확인했다.
ECS 첫 실행은 AWS 내부 오류로 생성 전에 실패해 실제 서버 실행 검증이 남아 있다.
수집·적재는 NGIP, scen_dev는 동일 DB의 읽기 전용 조회를 담당한다.
실행 방법·가용 기간·검증 결과는 [공개 데이터 수집 작업](11-open-data-jobs.md)을 따른다.

| 엑셀 기준 항목 | 현재 상태 | 확인된 연결 또는 보완 필요 |
|---|---|---|
| JKM·HH·TTF | 보유, 정의 확인 필요 | `hub_prices`, `hubs`, `gas_daily_prices`. 현물·선물·인도월 및 연결계열 규칙 확인 |
| WTI·Brent 및 2개월 시차 | 보유, 가공 필요 | `oil_prices`, `oil_contracts`. 계약 선택 및 월별 집계 후 시차 생성 |
| USD/EUR | 보유 | `market_indicators.eur_usd`. 환율 표기·방향 원천 확인 |
| 미국 국내 가스 수요 | 보유 | `gas_demand`, `gas_demand_us`, 부문별 수요. 엑셀의 Lower-48 범위와 정합 확인 |
| 미국 가스 생산량 | 보유 | `gas_production`, `gas_prod_us`, 분지별 생산. dry/marketed 및 지역 정의 확인 |
| 미국 LNG 수출 | 보유 | `lng_exports`, 터미널별 계열, `lng_cargo_exports`. feedgas와 수출량 구분 |
| 미국 파이프라인 수출, 멕시코향 순수출 | 일부 보유 | 멕시코 국경지점 `mx_*` 계열. 지점 코드·합산 대상·gross/net 및 캐나다 포함 범위 확인 |
| 아시아 LNG 수입 | 미확인 | 한국·중국·일본·대만 등 국가별 전체 수입과 지역 집계 필요 |
| 유럽 LNG 수입 | 미확인 | 국가별 전체 수입과 유럽/EU 집계 범위 정의 필요 |
| 글로벌 LNG 수출 | 미확인 | 주요 수출국 전체 수출 및 세계 집계 필요 |
| 호주 LNG 수출 | 미확인 | 미국산 LNG의 호주향 카고와 구분되는 호주 전체 수출 계열 필요 |
| 세계·MENA·호주 가스 생산 | 미확인 | 국가별 천연가스 생산과 일관된 지역 합계 필요 |
| 중국 파이프라인 수입 | 미확인 | LNG 수입과 구분된 파이프라인 수입 필요 |
| 유럽 Regas capacity | 미확인 | 국가·터미널별 재기화능력, 가동·증설 일정, 과거 이력 필요 |
| 글로벌·미국·호주·기타 액화능력 | 미국만 보유 확인 | 해외 액화설비·트레인·가동 일정과 연도별 용량 보완 필요 |
| 국가별 가스 수요·재기화 수입·이용률·저장량 | 미국 밖 범위 미확인 | 엑셀 Demand 시트의 국가·지역 범위 확보. LNG 탱크 재고와 지하 가스 저장 구분 |
| 수출국-수입국 LNG 교역 | 미국 출발만 일부 충족 | 호주·카타르·동남아 등 출발국을 포함한 양자 교역 필요 |
| LNG 용선료 | 부분 보유, 이력 부족 | `freight_symbols`+`freight_prices`: 아시아·대서양, TFDE·TWO_STROKE, 2025-04~. 엑셀 Steam·DFDE/TFDE·MEGI/X-DF 및 평균 정의 대조 |
| LNG 선박 인도량 | 미확인 | 엑셀 Charter rates의 선박 인도량 이력 별도 확보 |
| GDP·실질 GDP·성장률 | 중앙 DB 적재·조회 완료, ECS 실행 검증 대기 | World Bank job으로 265개 국가·지역의 1995~2025 데이터 확보. 한·중·일 합계는 별도 파생 필요. 실질 기준연도 2015 유지 |
| 미국 정책금리 | 미확인 | WTI 모델 Macro 계열 필요 |
| 미국 기온·평년편차·폭풍 건수/기간 | 부분 보유 | 주별 HDD/CDD는 있지만 엑셀 Weather의 TX·CA·NY·FL·IL 기온 및 폭풍 계열과 동일하지 않음 |

WTI의 OPEC+·비OPEC 생산과 전략비축유는 엑셀의 추가 구상 항목이다.
이미 값이 채워진 계열과 분리해 후속 수급 모델 요구로 관리한다.
현재 미국 원유 생산·재고 보유가 글로벌 원유 수급이나 전략비축유 전용 계열을
충족한다고 간주하지 않는다.

## 2. 지역 범위에서 확인된 사실

- `lng_sites`: 38개 사이트, country는 모두 US.
- `lng_vendor_projects`: 55개, country 분류는 Alaska 2개, US East 52개, US West 1개.
  이 값은 국가 코드가 아닌 벤더 지역 분류이므로 정규화가 필요하다.
- `lng_vendor_series`의 용량·계약량·gas into LNG도 Alaska·US East로 연결된다.
  2050년까지 값이 있어도 세계 공급 전망으로 취급할 수 없다.
- `lng_projects`의 `capacity_mtpa`, `target_online`은 확인 당시 값이 없었다.
  트레인별 용량·일정은 `lng_trains`를 읽어야 하며 중복 증설 여부 등을 검증해야 한다.
- `freight_series`와 `freight_rates`는 비어 있다. 현재 적재된 운임은
  `freight_symbols`와 `freight_prices`에 있다.
- `market_indicators` 전체 계열 목록에서 해외 가스 수급·Regas·GDP·정책금리
  전용 계열을 확인하지 못했다.

## 3. 보완 소스 후보

기존 엑셀의 S&P 자료와 DB의 Wood Mackenzie 자료는 이미 사용한 자산이다.
보유 원본·계약상 접근 가능한 해외 범위를 우선 확인한다. 현재 적재 범위만으로
벤더 계약에 글로벌 데이터가 포함됐다고 가정하지 않는다.

공식 안내를 확인한 외부 후보는 다음과 같다. 연결·다운로드·적재를 완료한 상태는 아니다.

| 후보 | 활용 대상 | 추가 확인 |
|---|---|---|
| [GIE LNG Database](https://www.gie.eu/transparency/databases/) | 유럽 LNG 터미널·재기화 설비 | 용량 정의, 국가 범위, 과거 버전·변경 이력 |
| [GIE ALSI/AGSI API 안내](https://www.gie.eu/transparency-platform/GIE_API_documentation_v005.pdf) | LNG 재고·send-out, 가스 저장 운영 데이터 | 현행 API 접근조건·키·커버리지 확인. 설비능력과 실제 흐름 구분 |
| [JODI-Gas](https://www.jodidata.org/gas/database/overview.aspx) | 국가별 월간 가스 생산·수요·LNG/파이프라인 수출입·재고 | 국가별 실제 제출 기간·결측·개정 검증. 2009년 이후를 제공한다는 안내가 모든 국가의 완전한 이력을 보장하지 않음 |
| [GIIGNL Annual Report](https://www.giignl.org/annual-report) | 글로벌 LNG 교역·액화·재기화능력의 연간 기준 및 대조 | 공개 PDF와 회원 전용 상세 Excel의 접근 범위 구분 |

GDP 소스/시리즈는 [World Bank job](11-open-data-jobs.md)으로 확정·실수집했다.
정책금리·기온·선박 인도량 및 양자 교역의 구체적 소스/시리즈 선정은 후속 확인 대상이다.

## 4. 데이터 정의와 연결 원칙

- 천연가스 생산량, LNG 생산량, LNG 수출량, 액화능력은 별도 변수로 관리한다.
- 재기화 설비능력, 가용능력, send-out 실적, LNG 수입량을 구분한다.
- 미국 수출의 도착국 집계는 해당 국가의 총 LNG 수입을 대체하지 않는다.
- 연간 능력과 월간 물량을 구분하고, bcm·Bcf·톤·에너지 단위 간 환산 근거를 남긴다.
- 과거 실적, 외부기관 전망, 우리 시나리오 가정을 구분한다.
- 국가별 시계열을 원천으로 보존하고 EU·유럽·아시아·MENA 집계의 포함 국가를 명시한다.
- 관측기간·발표/수집 시점·출처를 남기고, 외부 전망은 발간 시점과 전망 대상 기간을 구분한다.

## 5. 다음 작업 순서

1. 엑셀 원천 시트의 개별 국가·계열·기간을 목록화해 위 범주별 대조를 상세화한다.
2. 기존 DB/보유 벤더 원본에서 재사용할 계열과 추가 조달할 계열을 확정한다.
3. 유럽 Regas, 해외 LNG 공급·수출, 아시아·유럽 수요·수입을 우선 대조·보완한다.
4. 출처별 갱신 방식과 정의를 확인한 뒤 OUTLOOK의 읽기 계층과 별도 저장 위치를 설계한다.

이는 데이터 확보 범위 합의이며, 운영 DB에 신규 테이블을 만들거나 수집기를 배포하는 결정은 아니다.
