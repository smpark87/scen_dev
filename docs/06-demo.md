# Demo — 개념 실증

> **목적: 예측 정확도가 아니라 — 이 방법이 성립하는 모습을 보는 것.**
>
> **증명 대상은 하나다:**
> **임베딩된 비정형 정보가 실제로 통계 변수로 작동하는가.**
>
> 정답과 전혀 맞지 않아도 좋다. "데이터로 머신러닝"은 이미 익숙한 그림이고,
> 새로운 것은 그게 아니다.

---

## 0. 실행 결과 요약 (2026-08-03)

> **기계는 작동한다. 설명력은 나오지 않았다.** 둘 다 결과다.

| | 결과 |
|---|---|
| **성립한 것** | 의미 덩어리 20개 자동 발견 · 부호 있는 축 9개 추출 · 축의 외부 검증 통과 · 회귀 하네스 양방향 검증 통과 · 사건 코호트 구성 |
| **성립하지 않은 것** | 그 변수들이 HH 가격을 설명한다는 것 — **일자 패널·사건 코호트 두 단위 모두 null** |
| **핵심 반전** | 그 null 을 *"의미 축이 정형의 재탕이라서"* 로 설명할 수 없다. **축 9개 중 8개가 정형에 없는 정보를 담고 있음이 측정됐다** (§③′) |

**축이 실재한다는 증거** — `ax_2_0`(선물 코멘터리 안의 기온 방향)을 달력에 대면:

```
1월 −1.17(한파 얘기)  …  7월 +1.22(폭염 얘기)
```
계절 정보를 아무것도 넣지 않았는데 계절 곡선이 나온다.

**설명력 판정** (표본 외 R², 이동블록 부트스트랩 90% 구간) — 기준선을 배제한 것은 둘뿐:

```
T6 저장 nowcast    정형 +0.737 [+0.53,+0.84]   의미 +0.069 [−0.15,+0.12]
W1 베이시스 지속성   정형 +0.060 [+0.03,+0.10]   의미 −0.002 [−0.02,+0.00]
```
가장 근접한 것은 T7 꼬리에서 **의미 AUC 0.583 > 정형 0.512** 였으나 구간이 [0.47, 0.69]로
0.5를 포함한다 (양성 38건). **시사적이나 주장 불가.**

**사건 코호트** — 다섯 유형 모두 귀무분포와 구분되지 않는다 (양측 p 0.100~0.884).
다만 코호트의 **58~92%가 키워드에 걸리지 않은 문서**였다. 의미로만 찾아낸 것이며,
키워드로는 만들 수 없는 코호트라는 점은 확인됐다.

### 0.1 왜 안 나왔는지가 특정됐다 — 이것이 이 데모의 실질 산출

| 원인 | 실측 |
|---|---|
| **국면이 한 종류** | 분석창 2023~2026 전체가 저가·공급과잉. charter §6.2 기준 표본 5~6 |
| **위기 국면 부재** | 2021 Uri·2022 우크라이나의 의미 관계는 코퍼스에 아예 없다 |
| **밀도** | 평일 시장 문서 9.4건 |
| **기사가 사건보다 늦다** | 사건 코호트에서 **사전 표류가 사후 반응보다 크다** (지정학 t−5→0 +2.02% vs t+3 −2.96%) |
| **as-of 미적용이 정형에 유리** | 저장·리그가 발표 전 시점에 이미 값으로 있다. 정형의 우위에 이 이점이 섞여 있다 |

> 상용 뉴스 아카이브 조달의 근거가 **"있으면 좋다"에서 "이것 때문에 안 됐다"로** 바뀌었다.

## 1. 왜 이 단계가 먼저인가

| | |
|---|---|
| **문제** | 이 프로젝트의 핵심 주장 — *"뉴스·정책의 의미를 수치화해 정형 데이터와 함께 통계적으로 분석한다"* — 이 **말로만 존재한다.** 만드는 사람도 보는 사람도 실물을 본 적이 없다 |
| **해법** | 기존 데이터만으로 **그 주장이 성립하는지 눈에 보이게** 한다 |
| **하지 않는 것** | 정확도 검증 · 예측력 주장 · 판정 |

**Phase 0(방법론 검증)보다 앞선다.** 순서가 이렇게 된다:

```
Demo (3~4주)      →  Phase 0 (6~8주)  →  Phase 1~2 (6개월)  →  판정
"이런 게 나온다"      "성립하는가"        "쓸 만한가"
```

## 2. ⚠️ 가장 중요한 제약 — 이 산출물로 예측력을 주장하지 않는다

Demo는 **설명용**이다. 다음을 명확히 한다.

- **as-of 차단을 적용하지 않는다.** 미래 정보가 섞여 있을 수 있다
- **따라서 결과가 그럴듯해 보여도 그것은 예측력의 증거가 아니다**
- **Demo 결과는 04 §10.3의 판정 기준에 입력되지 않는다**
- 모든 화면에 **"설명용 · 예측력 검증 아님"** 을 표기한다

> 이 제약이 없으면, 보기 좋은 데모가 이후 판정을 오염시킨다 —
> 헌장 §7.4(결론이 정해진 실험 금지)가 금지하는 바로 그 경로다.

## 4. 무엇을 보여줄 것인가 — 증명 대상은 **하나**다

### 4.0 이것만 보여주면 된다

> **"데이터로 머신러닝"은 누구나 봤다. 새로운 것은 그게 아니다.**
>
> **임베딩된 비정형 정보가 실제로 통계 변수로 작동하는가** — 이것만 보이면 된다.
> Regime 타임라인·팬차트는 익숙한 그림이라 설득력이 약하다. **후순위로 둔다.**

### 4.0.1 ⚠️ "잔차 설명"으로 틀을 짜면 안 된다

초안은 *"정형으로 설명한 뒤 남은 잔차를 의미 변수가 설명하는가"* 로 잡았으나,
**이 틀은 두 가지를 미리 결정해 버린다.**

| 문제 | 내용 |
|---|---|
| **순서가 결과를 정한다** | 두 변수군이 상관될 때 **먼저 투입한 쪽이 공유 설명력을 전부 가져간다.** 정형을 먼저 넣으면 의미는 남는 것만 받는다 — 중립적 검정이 아니라 "정형 우선"이라는 가정이다 |
| **가장 불리한 곳에서 시험한다** | H1(01 §4.2)은 *"정형 = 현재 상태, Semantic = 전환의 선행신호"* 다. 그런데 **평상시 일간 변동은 정형이 지배하는 영역**이다. 거기서 잔차만 주는 것은 우리 가설과 어긋난다 |

> **"잔차가 별로 안 남으면?"** — 그것은 의미 변수가 무용하다는 뜻이 아니라
> **대상을 잘못 골랐다는 뜻**이다. 공선성이 질문에 따라 달라지듯(03 §5.1.2),
> **의미 변수의 기여도도 대상에 따라 달라진다.**

### 4.0.2 그래서 — 대칭 분해 + 다중 대상 + 국면 분할

**(가) 대칭적으로 분해한다.** 어느 쪽도 먼저 넣지 않는다.

```
정형만        →  R²_S
의미만        →  R²_M      ← 초안에 없던 것. 이것만으로도 강력한 결과다
둘 다         →  R²_SM

고유 정형 = R²_SM − R²_M      "숫자만 아는 것"
고유 의미 = R²_SM − R²_S      "뉴스만 아는 것"
공유      = R²_S + R²_M − R²_SM   "둘 다 아는 것"
```

이렇게 하면 **"어느 쪽이 더 중요한가"에 순서 가정 없이 답할 수 있다.**
그리고 `R²_M` 단독 값 자체가 설득력이 크다 — **"뉴스만 가지고 이만큼 설명한다."**

**(나) 대상을 하나로 두지 않는다.** 의미 변수가 힘을 쓸 만한 곳을 함께 본다.

| 대상 | 정형의 강점 | 의미의 예상 강점 |
|---|---|---|
| 일간 가격 변동 | **강함** | 약할 것 (평상시) |
| **방향 지속성** — 현재 추세가 N일 더 가는가 | 중간 (관성) | **관성의 *근거*를 담는다** — 아래 |
| **강도 변화** — 같은 방향이나 약해지는가 | 중간 | 기대·심리가 먼저 움직임 |
| **변동성 (실현·범위)** | 중간 | 불확실성은 텍스트에 먼저 |
| **국면 전환** | **약함** — 관계가 깨지는 구간 | 가설상 강함 |
| **공식통계 발표 전 구간** | **없음** — 데이터가 아직 없다 | **유일한 정보원** (nowcast) |
| 꼬리 (극단 변동일) | 약함 | 사건이 텍스트에 먼저 |

> **"방향 지속성"이 빠져서는 안 된다.** 정형 변수는 *"계속되고 있다"* 는 관성을
> 보여주지만, **왜 계속되는지는 담지 못한다.** 텍스트에는 그 근거가 들어 있고,
> **근거가 사라지면 관성도 곧 깨진다** — 이것이 선행 신호의 실체다.
> 실무적으로도 "지금 방향이 이어지는가"가 "언제 바뀌는가"보다 훨씬 자주 필요한 판단이다.

**(다) 국면을 나눠서 본다 — 이분법이 아니라 스펙트럼으로.**

```
지속(유지)  ─  강화 / 약화  ─  전환
```

01 §5의 Transition 정의가 **"유지·약화·전환 가능성"** 이라는 점을 그대로 따른다.
**전환만 보는 것은 이 시스템의 범위를 좁게 잘못 잡는 것이다** — 전환은 6년에 몇 번뿐
이라 표본도 적고, 대부분의 시간은 "지금 국면이 이어지는가"를 판단하는 데 쓰인다.

세 구간에서 기여도가 어떻게 달라지는지를 본다. **어느 구간에서 의미 변수가 힘을 쓰는지
자체가 결과이며**, 그것이 단일 ΔR²보다 훨씬 많은 것을 말해준다.

---

**설명한다면 — "숫자로는 안 보이던 것을 뉴스의 의미가 잡아냈다"는 뜻이다.**
이 프로젝트의 존재 이유(헌장 §5.2) 전체가 여기에 걸려 있다.

### 4.1 ⚠️ 이 실증의 핵심 함정 — 반드시 통제한다

> **같은 날 뉴스는 같은 날 가격을 "설명"하는 게 아니라 "보도"한다.**

동시점 상관은 거의 무의미하다 — 가격이 8% 빠졌으니 기사가 그 얘기를 쓴 것이다.
따라서:

| 구분 | 의미 |
|---|---|
| **동시점** (t 뉴스 ↔ t 가격) | 보도일 가능성 높음. **참고만** |
| **선행** (t−1 이전 뉴스 → t 가격) | **이것이 진짜 관전 포인트** |

두 경우를 **나란히 보여주고 차이를 명시한다.** 선행 관계가 약하게라도 잡히면
그것이 실질적 결과이고, 안 잡히면 그것도 정직한 결과다.

---

### ① 임베딩 공간 지도 — 의미가 구조를 갖는가

```
60,636개 청크 → 2차원 투영 → 시기별로 색칠
```

2022년 위기 문서들이 별도 영역에 뭉치는가? 코로나 시기는?
**"임베딩이 의미를 담고 있다"의 시각적 증명**이며, 설명이 필요 없는 그림이다.

### ② Semantic Factor 시계열 — **해석과 함께**

일자별 집계 → 소수 Factor → 2020~2026 그래프.

**여기서 결정적인 것은 그래프가 아니라 해석이다.**
각 Factor의 양 극단에 놓인 실제 문서 제목을 함께 보여준다.

```
Factor 1  (−) ← "파이프라인 정비로 공급 차질"  …  "재고 급증, 공급 과잉"  → (+)
```

이런 축이 나오면 **사람이 읽고 납득할 수 있다.** 안 나오면 블랙박스다.
**해석 가능성 자체가 산출물**이다.

### ③ 설명력 분해 — **핵심 지표**

§4.0.2의 세 원칙을 그대로 실행한다.

```
[대칭 분해]     정형만 R²_S  ·  의미만 R²_M  ·  둘다 R²_SM
                → 고유 정형 / 고유 의미 / 공유 로 분해

[시차별]        동시점 · 1일 · 3일 · 1주 선행     (§4.1의 보도/설명 구분)

[대상별]        일간변동 · 방향 지속성 · 강도 변화 · 변동성 · 전환 · 발표전 구간 · 꼬리

[국면별]        지속(유지)  ─  강화/약화  ─  전환      (스펙트럼)
```

**단일 숫자가 아니라 이 표 전체가 산출물이다.** 크든 작든 정직하게 보여준다.

정형 기준변수는 보유분으로 구성한다 — 저장량, 생산, 가격 시차, 계절성, (가능하면) 기온.

> **가장 보고 싶은 칸 두 개:**
> ① *방향 지속성* × *선행 시차* — "이 국면이 계속 갈 것인가"에 의미 변수가 기여하는가
> ② *전환* × *선행 시차* — 바뀌는 것을 미리 알려주는가
>
> **①이 ②보다 표본이 훨씬 많고 실무 활용도도 높다.** 둘 다 본다.

### ③′ 그 축들은 무엇을 담고 있는가 — 정형과의 중복 측정

**설명력을 재기 전에 볼 것.** 의미 축이 정형 변수의 다른 표현일 뿐이라면 기여가
없는 것이 당연하고, 그 경우 null 은 아무것도 말해주지 않는다. 가정하지 않고 잰다 —
각 의미 축을 정형 블록으로 회귀한다.

```
R²(축 | 정형) 높음  →  이미 숫자에 있다 (대체가능)
R²(축 | 정형) 낮음  →  숫자에 없는 것을 담고 있다 (고유)
```

**측정 결과 (표본 외 R², 기준 0.25)**

```
+0.334  대체가능   한파·난방 ↔ 폭염·냉방          ← HDD/CDD 에 이미 있다
+0.192  부분       국내 펀더멘털 ↔ 지정학·전쟁
+0.004  고유       원자력 폐로 ↔ 재생 성장
−0.005  고유       재생 건설 ↔ AI·데이터센터 수요
−0.008  고유       OPEC 정책 ↔ 교역 흐름
−0.009  고유       날씨 주도 ↔ EIA 재고 발표 반응
−0.015  고유       생산·공급 전망 ↔ 호르무즈·지정학
−0.019  고유       LNG 지연 ↔ 가동 개시
−0.039  고유       가계 난방비 ↔ 저장량 수준
```

**기온 축만 정형이 재현한다.** 예상대로다.

**예상과 달랐던 것 — "수준"과 "전망"은 다른 변수다.** `생산·공급 전망`이 −0.015 로
전혀 대체되지 않는다. 정형에 있는 것은 **실현 생산량**이고 텍스트에 있는 것은
**전망의 수정**(*"EIA, 올해 생산량 전망치 하향 조정"*)이기 때문이다. 저장량 축도
같은 이유로 −0.039 다. **수준은 숫자에 있으나 전망·해석은 어디에도 없다** —
비정형 고유 영역이 처음 생각보다 넓다.

**그럼에도 결과는 바뀌지 않는다.** 대체가능 축을 빼고 고유 8개로만 재분해해도
증분은 전부 0이다 (T1 +0.001 · T6 +0.000 · W1 −0.017).

> **편한 설명 하나가 막혔다.** *"의미 축이 정형의 재탕이라 기여가 없었다"* 는
> 이제 쓸 수 없다. **9개 중 8개가 숫자에 없는 정보를 담고도** 가격 설명에는
> 기여하지 않는다. 남는 해석은 ① 이 시평에서 가격과 무관 ② **너무 늦게 온다**
> (④′의 사전 표류 > 사후 반응이 지지) ③ 효과가 작아 이 표본으로는 탐지 불가.
> ③을 배제할 수 없으므로 정확한 표현은 **"효과가 없다"가 아니라 "탐지되지 않는다"** 이다.

**설계 결함 하나.** `ax_2_2`(+0.192)는 음극이 정형(생산·기온), 양극이 비정형(지정학)이라
**양 극의 성격이 다르다.** 다음 반복에서는 대비축이 아니라 지정학 강도 자체를 뽑아야 한다.

### ④ 대칭 설명력 분해 — 결과 화면

R²_S / R²_M / R²_SM 을 **신뢰구간과 함께** 가로 막대로 놓는다.
점추정만 그리면 구간이 0을 포함하는 결과가 발견처럼 보인다. 0선을 굵게 둔다.

> **~~④ 결정적 사례~~ (폐기, 2026-08-03).** 초안은 *"잔차가 크게 튄 날을 골라
> Semantic Factor 도 움직였음을 보인다"* 였다. **이것은 결과 기준 선별이다.**
> 잔차가 큰 날을 고른 뒤 무언가를 찾으면 반드시 나온다. 통계가 아니라 일화이며,
> "가장 강력한 장면"으로 쓰면 데모 전체가 체리피킹으로 읽힌다.
> 예시로는 쓰되 **통계적 주장에서 제외**한다.

### ④′ 사건 코호트 연구 — **분석 단위를 바꾼다**

날짜는 변수가 아니라 정합 키다. 시나리오는 본질적으로 *"X 가 일어나면 Y"* 이므로
**사건**이 자연 단위인 질문이 따로 있다.

```
씨앗: 제목 키워드로 잡는다 (출발점일 뿐)
확장: 임베딩으로 의미가 같은 문서를 찾는다  ← 여기가 대체 불가능한 부분
정렬: t=0 = 사건일. 달력 시간을 버린다. 창 [−5, +10] 영업일
검정: 같은 크기·같은 월 구성의 무작위 코호트 1,000회 → 실제 코호트의 백분위
```

**일화가 아니라 통계가 되는 3조건**
① 사건 정의에 결과(가격)를 넣지 않는다 ② t=0 정렬 ③ 귀무분포를 만든다

코호트 구성원을 날짜·제목과 함께 전부 나열한다 — 도메인 전문가가 *"7번은 이 유형이
아닌데"* 라고 말할 수 있는 검증 채널이 생긴다. R² 표에는 없는 장점이다.

### ⑤ 한계 시연 — **약점을 먼저 보여준다**

초안은 합성 문장쌍이었으나, **우리 실제 코퍼스에서 훨씬 강한 사례가 나왔다.**

`[09] 기상·가스수요 예보` 덩어리에서 축을 뽑았더니 세 축 모두 **형식**이었다
(기온 노트 vs 수요 노트 / 전국 vs 지역 / 정기 vs 속보). 본문을 보면 이유가 명확하다:

```
"The Lower 48 forecast has warmed by +5°F compared to the previous run"
"The Lower 48 forecast has cooled by a total of 3°F compared to the prior run"
```

**같은 템플릿에 단어 하나와 숫자만 다르다.** 서술형 기사(`[02]` 선물 코멘터리)에서는
기온 방향이 제1축으로 잡히는데, 정형 템플릿 노트에서는 잡히지 않는다.

> **경계가 실물로 그어졌다.** 임베딩은 어휘가 다른 방향(폭염/한파)은 구분하지만,
> **부정·비교로만 갈리는 방향(예상보다 많다/적다)은 구분하지 못한다.**
> 그래서 03 §5.4 `scen_event` 의 `direction` 필드와 구조화 추출(E6)이 필요하다 —
> 합성 예시가 아니라 우리 데이터가 그렇게 말한다.

> **약점을 먼저 제시하는 것이 신뢰를 만든다.** "다 된다"는 데모보다
> "여기까지 되고 여기서 막히며 그래서 이렇게 설계했다"가 훨씬 강하다.

## 6. 실제 결과 — 예상표와 대조

작성 당시 예상표에서 **"어느 대상에서도 고유 의미가 0 → 정직한 부정 결과"** 와
**"동시점만 잡히고 선행은 약함 → 가장 가능성 높은 결과"** 가 실제로 일어났다.

| 당시 예상 | 실제 |
|---|---|
| 동시점만 잡히고 선행은 약함 (*가장 가능성 높음*) | **적중.** 사건 코호트에서 사전 표류 > 사후 반응 |
| 어느 대상에서도 고유 의미가 0 | **적중.** 고유 의미가 구간상 0을 배제한 대상 없음 |
| 문서 밀도가 너무 얇음 | **적중.** 평일 시장 문서 9.4건 |
| Factor 축이 해석 안 됨 | **부분 반증.** 서술형 소스에서는 해석됐고, 템플릿형에서만 실패 (§⑤) |
| 특정 국면에서만 작동 | **미확인.** 설명변수 없이도 T1 이 고변동 59% / 중변동 43% 로 갈렸으나, 설명력 자체가 없어 검증 불가 |

### 6.1 이 null 이 뜻하지 않는 것

**① "의미 변수가 정형의 재탕이었다"가 아니다.** §③′ 에서 축마다 측정했다.
9개 중 8개가 `R²(축|정형) ≈ 0` 으로, **숫자에 없는 정보를 담고 있다.**
특히 *생산·공급 전망*·*저장량 전망*은 −0.015 / −0.039 로, 정형의 **실현치**와
텍스트의 **전망 수정**이 서로 다른 변수임을 보여준다.

**② "임베딩은 통계에 못 쓴다"가 아니다.** 아래 하네스 검증 참조.

하네스 자체를 먼저 검증했다 — 정답을 아는 합성 대상 3종에서:

```
순수 잡음        정형 −0.01   의미 −0.01
정형 3열 합성     정형 +0.896  의미 +0.13
의미 3열 합성     정형 −0.18   의미 +0.740
```

**양방향으로 대칭이다.** 의미 변수에 신호가 있으면 이 하네스는 찾아낸다.
못 찾은 것은 이 창·이 코퍼스에 없어서다 (§0.1).

> **조악한 결과가 나와도 실패가 아니다.** 목적은 정확도가 아니라 **"이 방법이 어떤
> 모습인지, 어디까지 되고 어디서 막히는지"** 를 실물로 확인하는 것이다.
> 막히는 지점이 드러났고, 그래서 다음 설계가 구체적이 된다.

### 6.2 실행 중 발견한 함정 — 재발 방지용 기록

| 함정 | 증상 | 원인 | 조치 |
|---|---|---|---|
| **비정상성** | R² −8 ~ −234 | 정형 17열이 강한 시간 추세(리그 −0.96, 퍼미안 생산 +0.96), 문서량 4.8→24.4. 시계열 분할에서 평가 구간이 학습 범위 **밖** | 후행 250일 표준화 (03 §5.2.1 을 코드에서 지킴) |
| **짧은 첫 학습창** | T6 R² −3.5 | 5분할이라 첫 학습이 7개월. 계절 지배 대상을 한 바퀴도 못 보고 외삽 | 최소 학습 2년 강제 → +0.737 |
| **수축 상한** | 신호 없을 때 R² 가 0 이 아닌 음수 | 능선 알파 상한 1e4 로 부족 | 1e7 까지 확장 |
| **문서 길이 편향** | 축이 의미 아닌 문서 종류 | 청크 기준으로 FERC 41%·STEO 18%인데 문서 기준으로는 16%·1.5% | 문서당 1표 가중 |
| **조건부 평균 잔존** | 덩어리 안 제1축이 언어·형식 | 전역 중심화는 전체 평균만 맞춘다 | 덩어리 **안에서** (소스×언어) 재중심화 |

## 7. 이 단계가 만든 것

1. **작동하는 파이프라인** — 읽기전용 추출 → 모집단 정의 → 편향 제거 → 의미 덩어리 →
   부호 축 → 일자 패널 → 대칭 분해 → 사건 코호트. 전 구간 재현 가능
2. **검증된 채점기** — 합성 대상 3종으로 양방향 검증. 이후 어떤 결과든 신뢰 가능
3. **정량화된 결핍** — 국면 5~6개, 위기 국면 0건, 평일 문서 9.4건.
   **아카이브 조달 요구가 정성 주장에서 수치 근거로 바뀌었다**
3.5 **변수 선택 지침** — 어떤 텍스트 특징이 숫자와 겹치고 어떤 게 안 겹치는지가
   **축 단위로 수치화**됐다 (§③′). 다음 반복에서 어디에 노력을 쓸지가 정해진다.
   특히 *전망·해석* 계열이 비정형 고유 영역임이 드러났다
4. **경계선** — 임베딩이 되는 곳(어휘가 다른 방향)과 안 되는 곳(부정·비교로만
   갈리는 방향)이 실물로 구분됐다 (§⑤)
5. **함정 목록** — §6.2. 다음 단계에서 같은 실수를 반복하지 않는다

## 8. 요청 → 다음 단계

> 당초 요청: **추가 예산 없이 3~4주.** 기존 데이터·인프라만 사용, 산출물은 화면 1장,
> 예측력 주장 없음. — **그대로 지켜졌다.**

결과를 받은 뒤의 요청은 달라진다.

| 요청 | 근거 |
|---|---|
| **뉴스 아카이브 조달** (2015~2022) | 위기 국면이 코퍼스에 0건. 국면 표본 5~6 → 15~20 (§0.1) |
| **as-of 적용** | 현재 정형의 우위에 발표 전 값이 섞여 있어 비교가 불공정 |
| **구조화 이벤트 추출** (`direction` 필드) | §⑤ 의 경계선이 실물로 확인됨 |

> **이 세 가지 없이 같은 실험을 반복하면 같은 null 이 나온다.** 데모의 결론은
> "안 된다"가 아니라 **"이것들이 갖춰져야 판정이 가능하다"** 이다.
