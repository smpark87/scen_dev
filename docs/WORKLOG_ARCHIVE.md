## 2026-09-25 — 공통 개발 규율 이식

NGIP와 LAI Finance의 공통 작업 원칙을 `AGENTS.md`에 맞춰 정리했다. 기존 보안 게이트는 유지하고 전체 Python 테스트 CI, 품질 래칫, Git 훅의 래칫 실행을 연결했다. 제품·재무 시스템에만 적용되는 규칙과 판정 숫자는 복사하지 않았다. 로컬 개발 실행 경로는 `../shared/.venv`로 통일하고 공용 명세·lock에 필요한 의존성을 추가했다. 공용 환경에서 scen_dev 테스트 54개, LAI Finance 219개(54건 건너뜀), 평가모델 15개, NGIP 의존성·코어 import 검사 124개가 통과했다. `pip check`·래칫·보안 게이트·사전 점검·Git 훅도 통과했고 OUTLOOK loopback 리스너 기동을 확인했다. 본사 GUI 도구의 실제 검사는 별도 실행·판정 대상이다.
